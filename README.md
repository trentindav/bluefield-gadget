# BlueField3 Gadget Snap

This repository contains the Ubuntu Core gadget snap for the BlueField3
arm64 processor.
This gadget is a modified version of the `core22` `pc` gadget, used for testing
purposes, and modified to be used with `core24`.

## Building

To build the gadget snap locally please use `snapcraft pack`.
Cross-compilation from amd64 to arm64 is not supported at this time.
